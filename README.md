# File Organizer

Um programa simples e prático para **organizar automaticamente os arquivos das suas pastas**. Ele separa arquivos por tipo (imagens, vídeos, documentos e outros) em subpastas, deixando tudo limpinho.  

Este projeto já vem **como .exe pronto**, então **não precisa instalar Python nem dependências**. Só rodar e usar.

---

## Funcionalidades

- Organiza arquivos automaticamente por tipo:
  - Imagens (`.jpg`, `.png`, `.gif`, etc)
  - Vídeos (`.mp4`, `.mkv`, `.avi`, etc)
  - Documentos (`.pdf`, `.docx`, `.txt`, `.xlsx`, etc)
  - Outros arquivos em uma pasta separada
- Roda direto no Windows como `.exe`
- Não precisa de Python nem instalar libs adicionais

---

## Como usar

1. Baixe o arquivo `.exe` do projeto.
2. Coloque ele na pasta que você quer organizar **ou configure o caminho dentro do arquivo, se necessário**.
3. Execute o `.exe` clicando duas vezes.
4. Espere enquanto ele organiza os arquivos em subpastas.
